Kantong Rumah adalah situs anggaran keluarga berbahasa Indonesia yang berjalan
sepenuhnya offline dari file statis: Dashboard (pemasukan, pengeluaran, sisa,
donat per kategori), Transaksi (tambah, hapus, filter, tersimpan di
localStorage), Anggaran (batas per kategori dengan batang terpakai vs anggaran
yang bisa diubah), Tagihan (tagihan rutin dengan tanggal jatuh tempo dan tombol
tandai lunas), dan Laporan (grafik pemasukan vs pengeluaran 6 bulan dan tips
hemat). Angka-angkanya nyata dan konsisten — pemasukan Rp 8.500.000 per bulan,
pengeluaran November 2026 Rp 4.670.000 — dan setiap kontrol benar-benar bekerja.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Lalu buka http://localhost:8080 di browser (desktop atau HP). Tidak perlu
instalasi, tidak perlu akun, tidak ada request jaringan.
